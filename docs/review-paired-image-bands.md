# 同一CASE内のNEW／OLD画像段の配置

同じ側の配置順と反対側の配置順を対応させ、管理画像の同じ枚数どうしを一段として扱う。
次段は前段の両側の下端から2行の余白を確保する。後から追加する画像が反対側の次段に
達する場合、次段の開始行に行を挿入し、後続画像とCASEを下げる。
同じ段の参照画像はこの占有判定から除き、既存の開始行・共通倍率の対応を維持する。

行挿入は既存の補償・Undo/Redo履歴へ記録する。Redoでも挿入行高を初回と同じ15ptに
正規化する。セル内容との衝突や保護などで安全な配置ができない場合は停止する。
通常の1枚ずつの自動配置を対象とし、Excelで手動貼り付けされた非管理画像には段番号を推定しない。

## 検証

- 通常テスト140件成功。
- 実Excelの一時ブックでNEW2枚→縦長OLD1枚→OLD2枚の配置に成功。
- OLD1枚目追加後、NEW2枚目が両側の1枚目下端より2行超下にあることを検証。
- 同じ枚数の両側画像の開始行・Top座標の一致を検証。
- OLD1枚目と追加行を取り消し、既存画像の開始行・Top・高さの復元を検証後、再配置に成功。
- 参照画像の倍率変更の取り消し・再適用を検証。
