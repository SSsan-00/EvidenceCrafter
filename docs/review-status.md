| 両Side完成後も空行が残る | New/Old双方に管理画像がある場合だけ、安全な末尾空行を削除して2行を維持 |
| A列が空のAnchorでCaseが`2`だけになり重複する | 確定Anchor間でA列の親番号を継承し、検索・表示・前後移動を共通の`X-X`表現へ統一。真の重複は該当行を表示して安全停止 |
| EvidenceCrafterとExcelの処理が重い | UsedRange数式と連続罫線をRange単位で一括取得し、曖昧時だけ従来のセル走査へフォールバック。選択監視は解析中の最新イベントだけをキャッシュへ適用 |
| 行操作後にシートへ灰色の破線が表示される | 行操作前の`DisplayPageBreaks`を保存・復元し、ネイティブ行Snapshotの内部コピー終了時に`CutCopyMode`を解除 |
| New/Old完成後の次Case検索が遅い | Case移動を軽量Snapshotへ変更し、コメント・リンク・占有セル・行高・列幅の不要なCOM取得を省略。末尾整理と検索の状態表示も分離 |
| 罫線なし雛形を解析できない | 数値Case番号と「新／旧」ヘッダーを主信号に変更。罫線は警告用の補助信号とし、セル単位の連続罫線走査を廃止 |
| NewだけのCaseでOldが提示される | シートをNewのみ／New・Oldに分類し、NewのみではOld選択、反対Side遷移、完成時の自動行削除を無効化 |
| ROTの対象外COMでExcel列挙全体が失敗する | IDispatch非対応または切断済みのCOMオブジェクトを個別に読み飛ばし、他のExcel Workbookの探索を継続 |
| 二重起動で複数ウィンドウが開く | セッション単位の名前付きMutexと通知イベントで単一起動を保証し、最小化状態や所有モーダル画面を復元 |
| New/Oldの対応画像の倍率がそろわない | 管理画像の元寸法をメタデータへ保存し、同じCASEの序数画像を共通倍率へ計画。既存画像の拡縮・必要行の予約・配置を一履歴としてUndo/Redo可能にした |

## 安全境界

- Workbook identity、Excel PID、Window handle、Window token、ReadOnly、Sheet保護を変更直前に再検証する。終了イベント監視やEnableEventsの状態だけでは操作を拒否せず、EnableEventsは操作前の値へ復元する。
- Snapshot fingerprintが変化した場合は自動配置を中止する。
- 複数ステップ配置は途中失敗時にShape→挿入行の逆順で補償する。
- 削除対象行に値、数式、コメント、リンク、Shape、結合があれば削除しない。
- Workbookは自動保存しない。参照フォルダは変更しない。
- 対応画像の共通倍率は両Sideの利用可能幅の小さい方を上限にする。既存画像が旧形式で元画像寸法を持たない場合は、現在表示されている幅・高さからアスペクト比を近似して合わせる。
- 倍率変更後に他の図形と重なる場合、または既存画像・行がユーザー操作で変更された場合は、変更を停止して安全側へ戻す。

## 環境横断の手動受入項目

100/150/200% DPI、複数モニター、Office x64、clean VM、OneDrive/ネットワークパス、20画像連続操作は、当該ホスト単体の自動検証ではなくリリース時の環境横断確認対象とする。

行削除Undoは削除行をネイティブExcel形式で一時退避し、空セルの独自行高・罫線・入力規則・条件付き書式を含めて復元する。対象Worksheetの参照数式、Workbook名前定義、印刷範囲も退避する。別Sheetに数式がある場合、または安全確認範囲が250,000セルを超える場合は行削除を安全停止する。削除後またはUndo後に対象状態が変更されている場合も履歴操作を行わない。
