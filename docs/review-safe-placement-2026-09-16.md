# 整合性を確認した配置の継続

参照画像の倍率変更に失敗した場合、復元成功を確認できたときだけ、対象Sheet・CASE・Sideを固定して最新状態を再解析する。

再解析では既存の参照画像の大きさを保持する。元画像寸法を取得できる画像は現在の表示倍率を基準にし、元寸法がない画像は現在の表示幅を基準にする。追加画像が配置幅を超える場合は収まる倍率へ縮小するため、この回復経路では左右の倍率が異なることがある。

対応画像と開始行を合わせ、後続画像との間隔・セル内容・CASE境界・行上限は通常の配置計画で検証する。共通倍率による計画を作れない場合も、参照画像を変更しない計画を一度試す。復元失敗、保護、開始位置のセル内容との衝突などは停止する。

配置後は既存の画像位置・サイズ検証とUndo/Redoの履歴処理を使用する。回復配置では参照画像のサイズ変更履歴を作らない。

検証対象:
- 小さい参照画像の現在倍率を維持し、後続画像用の行間隔を確保する計画。
- 通常倍率ではセル内容と衝突するが、現在倍率なら収まる場合の計画回復。
- 開始位置のセル内容や保護シートでの停止。
- 実Excelで参照画像の拡大先に図形を置き、倍率変更失敗・追加行復元・反対側への配置を確認。参照画像の幅・高さと対応画像の開始位置を検証。
- 既存の複数画像配置・行追加・Undo/Redo検証。
